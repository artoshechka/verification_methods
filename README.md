# Методы верификации

Репозиторий с домашними заданиями по предмету **«Методы верификации»**.

Задания выполнены на языке Promela и предназначены для проверки с помощью
инструмента SPIN:

- `task1/` — примеры взаимодействия процессов и передачи сообщений по каналам;
- `task2/` — задача о переправе через реку с проверкой свойств системы;
- `task3/` — задача об обедающих философах с официантом и ограничением
  количества одновременно ожидающих философов.

Файлы `.pml` содержат исходные модели и формулировки проверяемых свойств.
